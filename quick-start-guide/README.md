# Quick Start Guide: Setting Up a Secure Network in AWS with a Virtual Private Cloud

A procedural quick start guide written for Ensign College IT students who are starting their first cloud computing coursework. It walks a beginner through building a working AWS network in about 15 to 20 minutes, with the exact settings to use and the order to use them in.

**[Read the guide (PDF)](AWS_VPC_Quick_Start_Guide.pdf)**

## What the Guide Covers

The reader builds a Virtual Private Cloud (VPC) in five steps:

1. Create the VPC (10.0.0.0/16)
2. Create a public subnet (10.0.1.0/24)
3. Attach an internet gateway
4. Add a route to the internet
5. Create a security group (SSH from My IP only, HTTP from anywhere)

It also includes a "Check Your Work" checklist, a troubleshooting table for common problems, and clean-up advice for avoiding unexpected AWS costs.

## Writing Choices

- **Audience first:** written for beginners, with each step depending on the one before it
- **Visuals:** an architecture diagram and a five-step flow diagram
- **Security habit built in:** the guide tells readers never to allow SSH from anywhere
- **APA formatting** with figures, tables, and references

## Skills Demonstrated

- Technical writing for a defined audience
- AWS networking fundamentals (VPC, subnets, internet gateways, route tables, security groups)
- Procedural documentation and troubleshooting guidance
- Designing diagrams that support instructions
